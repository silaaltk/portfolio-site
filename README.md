# Portfolio Site
This project is a personal portfolio site built using **Next.js and React**.

## Live Site
You can view the deployed portfolio here:  
[https://silaaltk-portfolio-site.vercel.app](https://silaaltk-portfolio-site.vercel.app)

## Getting Started

To run this project locally, follow these steps:
 

```bash
1-Clone the repository:
git clone https://github.com/silaaltk/portfolio-site.git

2-Navigate to the project folder:
cd portfolio

3-Install dependencies:
npm install

4-Start the development server:
npm run dev

5-Open your browser and visit:
http://localhost:3000
